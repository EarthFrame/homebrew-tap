# EarthFrame Homebrew Tap

Official [Homebrew](https://brew.sh) tap for EarthFrame utilities.

## Installation

Add this tap and install `mar`:

```bash
brew tap earthframe/tap
brew install mar
```

Or install directly in a single command:

```bash
brew install earthframe/tap/mar
```

## Available Formulae

| Formula | Description |
| ------- | ----------- |
| [`mar`](Formula/mar.rb) | Universal Data Container and high-performance archival utility |

## Development & Upgrades

To build from source or install the latest development version:

```bash
brew install --HEAD earthframe/tap/mar
```

To update to the latest release:

```bash
brew update
brew upgrade mar
```

## Documentation

For full documentation, benchmarks, and usage guides, visit the [MAR repository](https://github.com/earthframe/mar).
